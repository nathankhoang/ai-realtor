## How to Rerun with Paid Gemini

1. **Set up Gemini paid API key:**
   ```bash
   export GOOGLE_API_KEY="your-paid-gemini-key"
   ```

2. **Confirm available Gemini model IDs:**
   ```bash
   npx tsx scripts/vision-eval/list-gemini-models.ts
   ```

3. **Update `.env.local` with actual model IDs if different:**
   ```bash
   GEMINI_FLASH_MODEL=gemini-2.5-flash
   GEMINI_PRO_MODEL=gemini-2.5-pro
   ```

4. **Reseed vision ground truth** (use latest analysis):
   ```bash
   npx tsx scripts/vision-eval/seed-smoke-labels.ts
   ```

5. **Run comparison:**
   ```bash
   npx tsx scripts/stack-eval/stack-compare.ts
   ```

Output goes to: `scripts/stack-eval/results/compare-{timestamp}.{md,csv}`

## Architecture Notes

The comparison script:
- **Reuses existing eval infrastructure:** Vision prompts, scoring logic, DB connections from `scripts/vision-eval/eval.ts`
- **Standalone and extensible:** No changes to production code; easy to add new models or tasks
- **Realistic workloads:** Uses actual DB listings, synthetic judgment cases calibrated to real search patterns
- **Ground-truth strategy:** Vision uses auto-seeded labels (Sonnet-biased); requirements/judgment use hand-coded test cases with expected outputs
